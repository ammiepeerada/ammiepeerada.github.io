About / เกี่ยวกับแอป

Tonkla Backup is a private tool used only by Tonkla for Kids School (Pak Chong, Nakhon Ratchasima, Thailand) to store encrypted backups of its own school management system in the school's own Google Drive.

Tonkla Backup เป็นเครื่องมือภายในที่ใช้เฉพาะโรงเรียนกวดวิชาต้นกล้า ฟอร์ คิดส์ เพื่อเก็บไฟล์สำรองข้อมูล (เข้ารหัสแล้ว) ของระบบบริหารโรงเรียนไว้ใน Google Drive ของโรงเรียนเอง

Privacy Policy / นโยบายความเป็นส่วนตัว

Last updated / ปรับปรุงล่าสุด: 29 October 2026

Who uses this app

  • This app is not offered to the public. Only the school's administrator signs in to it.

Google user data we access

  • It uses only the Google Drive permission drive.file, so it can access only the files it creates itself. It cannot see any other files in Google Drive.
  • It uploads, lists, and deletes encrypted backup files in one folder.

How the data is used and shared

  • Backup files are encrypted before they are uploaded, and are used only to restore the school's own system.
  • It does not read, sell, or share any personal Google account data with anyone, and does not use it for advertising.
  • Tonkla Backup's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and deletion

  • Backup files are stored only in the school's own Google Drive. The administrator can delete them at any time from the app or from Google Drive.
  • Access can be revoked at any time at Google Account → Third-party access.

สรุปภาษาไทย

  • แอปนี้ไม่ได้เปิดให้บุคคลภายนอกใช้งาน มีเพียงผู้ดูแลระบบของโรงเรียนเท่านั้นที่ลงชื่อเข้าใช้
  • เข้าถึงได้เฉพาะไฟล์สำรองที่แอปสร้างขึ้นเองเท่านั้น (สิทธิ์ drive.file) มองไม่เห็นไฟล์อื่นใน Google Drive
  • ไฟล์สำรองถูกเข้ารหัสก่อนอัปโหลด และเก็บไว้ใน Google Drive ของโรงเรียนเท่านั้น
  • ไม่มีการขาย หรือเปิดเผยข้อมูลให้ผู้อื่น และไม่นำไปใช้เพื่อการโฆษณา
  • ยกเลิกสิทธิ์การเข้าถึงได้ทุกเมื่อที่หน้า การเข้าถึงของบุคคลที่สามในบัญชี Google

Terms of Use / ข้อกำหนดการใช้งาน

  • Tonkla Backup is for internal use by Tonkla for Kids School only. No one else is permitted to use it.
  • The school is responsible for keeping its administrator account and encryption key safe.
  • The app is provided as is, for the school's own backup purposes.
  • Tonkla Backup ใช้ภายในโรงเรียนกวดวิชาต้นกล้า ฟอร์ คิดส์ เท่านั้น ไม่อนุญาตให้บุคคลอื่นใช้งาน
  • โรงเรียนมีหน้าที่ดูแลบัญชีผู้ดูแลระบบและรหัสสำหรับเข้ารหัสไฟล์ให้ปลอดภัย
